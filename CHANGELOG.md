# Changelog

Notable changes are recorded here. Each feature uses independent
[Semantic Versioning](https://semver.org/).

## v0.1.0 — Initial release

- Added a Node.js feature with checksum-verified official binaries and npm.
- Added a Python feature with distribution packages, venv, and optional pip.
- Added default, option, repeat-installation, and combined non-root shell tests.
- Added test and manual GHCR publishing workflows.
- Added contributor documentation and a development container using local installers.
