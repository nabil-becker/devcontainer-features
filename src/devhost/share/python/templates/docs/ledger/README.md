# The ledger

The append-only record of what agents did in {{REPO_NAME}}: one entry per unit of work, in
monthly files `YYYY-MM.md`, oldest first. Beside them, `costs-YYYY-MM-<engineer>.md` is the
month's agent-cost report for one engineer's machine, generated by `devhost-report` (and by the
briefing at every session start), never edited by hand.

## Who writes

- The **scribe** back writes the entries after each inter turn and after each con's job, inside
  the devhost, and fills the Measures line from the transcripts (`devhost-costs --measures`).
- A **host** writes an entry by hand only on a workstation (no backs there) or to correct one:
  a wrong entry is never edited; a new entry with a `Corrects:` line replaces it.
- The **review** (`/ledger-review`) appends a `## Review YYYY-MM-DD` section every five or so
  entries, after reading the cost report.

## Shape

A monthly file starts with one heading line, `# Ledger, YYYY-MM`. Each entry is:

```
### YYYY-MM-DD <short title: what was done>

- **Session:** <"scribe (<session id>)" for a host session; "con <agent type> (<agent id>)" for a con's job>
- **Engineer:** <who>
- **Branch:** <branch>
- **Asked:** <what the Operator asked for, or the con's brief, one line>
- **Skill:** <the skill used, or "none">
- **Came out:** <the outcome in a line; the paths written, the ids added or changed>
- **Friction:** <each item with its tag: [tooling], [docs], [skill: <name>], [skill: new], [process]; or "none">
- **Learned:** <a pattern that worked, a surprise, a question the work raised; or "none">
- **Decisions:** <what the Operator decided during this work, in their words where short; or "none">
- **For the repository:** <what should change in the shared tooling, documents or skills, tagged; or "none">
- **Decisions needed:** <what only the Operator can decide; or "none">
- **Measures:** <the cost, tokens and models, filled by the scribe's script>
- **Corrects:** <only on a correcting entry: the date and title of the entry it corrects>
```

The only headings are `### YYYY-MM-DD <title>` and `## Review YYYY-MM-DD`. `devhost-verify`
refuses a commit that changes or removes a line that is already on the base branch, or a file
in this directory that is not a monthly file, a cost report or this README. Paths and ids,
never content: no real data, credentials, identifiers or forbidden words.
