# The white papers

One paper per iteration of the Agentic Delivery OS (`docs/iterations.md`), carried forward
unchanged in every iteration package (ADR 0008). An original is kept byte for byte and never
edited; a derived Markdown copy beside it is for agents, says so in its front matter, and loses to
the original wherever they differ.

| Paper | Iteration | Original | Derived copy |
|---|---|---|---|
| "From seed to tree" | 1, the office | `01-from-seed-to-tree.html` (sha256 `73cf00fb…8d83`), as software project 1 received it | `01-from-seed-to-tree.md` |
| "From tree to seed" | 3, this repository (devcontainer-features) | `iteration-3.md` | none: written in Markdown |

Iteration 2 (software project 1) wrote no paper; it read paper 1 and was set up from it, and the
third paper names what came from it. The papers call the projects "the office" and "software
project 1" (closing interview 3, questions 15 and 20).

The originals carry their author's byline. The Operator approved that as an exception to the name
guard on 2026-10-19; the files are listed in `.devhost/name-exceptions.txt`.
